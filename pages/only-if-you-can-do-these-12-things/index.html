Principles: Only If You Can Do These 12 Things

24 August 201824 สิงหาคม 20182018年8月24日

This entry is in English only.บันทึกนี้มีแต่ภาษาอังกฤษ此篇仅有英文。

Only if I can do these things, I’d be the happiest person alive. I want to stick to the number twelve, as my previous post has suggested.

Honestly, I cannot do all of these. I can do about half of these. Maybe you can guess which of these that I can do.

How many can you do?

I promise if your life will be much much much better if you can do more than half of these. Your life, however, will be complete if you can do all of them. I promise.

  1. Only if I can live in the present without regretting the past past or being worried about the yet-to-come future;
  2. Only if I can tell myself not to take others’ problems as my own;
  3. Only if I could stop comparing myself to others, and only to myself yesterday;
  4. Only if I could focus only on the process and intention, and not the outcome of that into which I have put my effort;
  5. Only if I could differentiate between “true” and fake friends;
  6. Only if I could forgive myself for what I might have done because of my very own ignorance;
  7. Only if I can be happy with what I already have, rather than miserable about what I don’t have;
  8. Only if I choose with whom do I want to spend the precious remaining time that I have left on the earth;
  9. Only if I can say to those who want to do or have already done me harm, “I forgive you, so please forgive yourself”;
  10. Only if I could have a job that gives me both the pleasure of working as well as the happiness of working for the right cause;
  11. Only if I no longer have to rely on gossip, rumors, scandals, and unsubstantiated external news (they are the same bad thing) to live in this world; and, finally,
  12. Only if I could entirely choose what I eat (and it would be entirely healthy stuff).

How many can you do?
